# V12 classes: dictionary, scripts, events, instances

How V7+/V12 business classes are declared (GESACLA), where their code lives (class scripts with
`$EVENTS`, `$PROPERTIES`, `$METHODS`, `$OPERATIONS`), which events run inside the supervisor
transaction, how other code uses instances, and how errors are reported. Read it before writing or
reviewing a class script. There is **no** `Class ... Endclass` source syntax: a class is dictionary
metadata, plus code generated at validation, plus the event scripts you attach to it.

## Class dictionary (GESACLA)

Seven tabs: Header (class code `CODCLA`), General (management mode, Collections grid, Scripts grid),
Methods, Standard methods, Properties, Mapping, Miscellaneous.

| Type (`TYPCLA`) | Meaning |
|---|---|
| Persistent | Stored in the database; CRUD can be generated by the supervisor. Main table `WTABREF`, key index `WINDREF` |
| Interface | Not linked to tables; you write CRUD in the `AINSERT`/`AREAD`/`AUPDATE`/`ADELETE` events. `FLGTR` (transaction management) applies only here |
| Basic | Accessors and methods, no mapping; typically child classes of a persistent class |
| Technical | Methods but no accessors; properties cannot appear in representations |
| System | Data structure only, no accessors, no methods |

- **Mapping tab**: Reading / Creation / Modification / Deletion checkboxes (`FLGRREF`, `FLGCREF`,
  `FLGUREF`, `FLGDREF`). Cleared = no generated code; you write it in the matching CRUD event. In the
  joins grid, *Class management* (`FLGA`) delegates CRUD of a child table to the child class.
- **Properties tab**: name properties exactly like the table columns of a persistent class (otherwise
  extra mapping code is needed). *Mandat* (`OBLIG`), *Control table* (`CODCTL`), *GET accessor*
  (`FLGACCGET`, enables the GET rule; costly, enable sparingly), *Order* (`NUMFLD`, order of generated
  init/control code).
- **Validation** checks consistency, generates the class into `C_<class>.stc` plus the CRUD/event
  scripts. Generated programs are rewritten at every validation: never edit them. *Options > Global
  validation* revalidates all classes of the folder. An unvalidated class fails at execution.
- **Activity code** starting with X, Y or Z protects a class, script, method or property line from
  standard patches; an inactive activity code removes it. See `personalisation-activity.md`.

## Scripts grid and naming

| Column | Use |
|---|---|
| Type (`TYPTRT`) | Standard, Vertical or Specific |
| Scripts (`CODTRT`) | `<class>_Cyyyy`, yyyy starting with `STD`, `VER` or `SPE` (GESACLA); default proposed from class code + type |
| Running order (`RANTRT`) | Order in which each script's labels are called for an event |
| Activity code (`ACTTRT`) | Inactive = call skipped; X/Y/Z = protected during patches |

The developer guide adds: the default standard script is `<CLASS>_CSTD` with rank 1000, ranks that are
multiples of 1000 are reserved for standard extensions, specific and vertical script names should start
with X, Y or Z, two scripts cannot share a rank. For your own class `YCUSTLOG` the specific script
`YCUSTLOG_CSPE` satisfies both rules.

## Labels and dispatch variables

| Label | Called for | Dispatch | Notes |
|---|---|---|---|
| `$EVENTS` | Standard events (AINIT, CRUD...) | `Case [L]CURPTH` then `Case [L]AEVENT` | `CURPTH` empty = this class, else path to the child |
| `$PROPERTIES` | Property rules | `Case [L]CURPRO` then `Case [L]ARULE` | `CURPRO` is relative: `"LINES.PROP"` in the header script, `"PROP"` in the line script |
| `$METHODS` | Methods of the class | `Case [L]AMETHOD` | Only scripts of the defining class; `CURPTH` not usable |
| `$OPERATIONS` | Operations of the class | `Case [L]AOPERATION` | Same scope rule; stateless |

- Return value of a method or operation: **`[L]ARET_VALUE`**. The classes-events page prose writes
  `ARETVALUE`, but GESACLA, the representation reference, the error-handling guide and every Sage code
  sample use `ARET_VALUE`. Its type is the method's *Return type* (`DONMET`).
- Each label ends with `Return`. Scripts are entered by `Call` followed by `Gosub`: locals declared in
  one event are invisible in the next, and tables opened in an event are closed when it ends, so
  declare `Local File` at the start of each event label.
- V11 split the old `$METHODS`/`$ACTION` dispatch into these four labels; `$ACTION` was kept for
  compatibility and announced as deprecated in V12. Some Sage how-to pages still show the old layout
  (`$METHODS` + `Case ACTION` for events): do not copy it into new code.

## Property rules

| `ARULE` | When | What you may do |
|---|---|---|
| `INIT` | Create link, grid line insert, `ADDLINE`, explicit `AINIT`; final call with empty `CURPRO` | Default values |
| `GET` | Property read, only if *GET accessor* is set | Compute the value |
| `CONTROL` | Every assignment (except in `AREAD_AFTER`) and final control before insert/update, after mandatory and format checks | Check and call `ASETERROR`; no direct update of properties |
| `PROPAGATE` | After `CONTROL` accepted a changed value | Assign other properties of `this` |

`A.PROP1 = A.PROP2` runs GET on PROP2, CONTROL on PROP1, then PROPAGATE on PROP1 if it changed. In
CONTROL, `this.PROP` already holds the new value and `this.snapshot.PROP` the value at operation start.

## Events

| Group | `AEVENT` values | Transaction |
|---|---|---|
| Global | `AINIT` (after all INIT rules), `ACONTROL` (after all CONTROL rules, children first) | No |
| CRUD operation | `AINSERT`, `AREAD`, `AUPDATE`, `ADELETE`: only when the Mapping checkbox is cleared or the class is Interface; your code does the I/O | Yes for `AINSERT` (documented) |
| CRUD control | `AINSERT_CONTROL_BEFORE`/`_AFTER`, `AUPDATE_CONTROL_BEFORE`/`_AFTER`, `ADELETE_CONTROL_BEFORE`/`_AFTER` | **No**, and no data update allowed |
| CRUD update | `AINSERT_BEFORE`/`_AFTER`, `AUPDATE_BEFORE`/`_AFTER`, `ADELETE_BEFORE`/`_AFTER` | **Yes**: an error aborts and rolls back |
| CRUD error | `AINSERT_ROLLBACK`, `AUPDATE_ROLLBACK`, `ADELETE_ROLLBACK` | After rollback |
| Collection | `ADDLINE_BEFORE`/`_AFTER`, `ADELLINE_BEFORE`/`_AFTER` (`this` = line, `CURPTH` = collection) | - |
| Read | `AREAD_BEFORE`, `AREAD_AFTER` (`[F:abv]` buffer filled; values set here become the snapshot) | - |
| Query | `AQUERY_DECODE_CRITERIA_AFTER`, `AQUERY_PRIMARYKEYS_AFTER`, `AQUERY_OPEN_AFTER`, `AQUERY_CRITERIA_AFTER`, `AQUERY_JOIN_AFTER`, `AQUERY_TRANS_AFTER`, `AQUERY_CLOSE_AFTER` (representations only; see `v12-representations.md`) | - |
| Search | `ASEARCH_OPEN_AFTER`, `ASEARCH_JOIN_AFTER`, `ASEARCH_TRANS_AFTER`, `ASEARCH_CLOSE_AFTER` | - |

`*_CONTROL_BEFORE` runs before the property controls and is the place for defaults. Nested classes:
"before" events descend (header, line, sub-line), each parent script being called again with `CURPTH`
= child path; `AINSERT_AFTER` ascends (sub-lines first). On update, each child's `this.ASTALIN`
decides whether insert, update or delete events fire for it. There are no `afterLoad`/`beforeSave`
events.

## Transactions in events

- The supervisor owns the transaction around CRUD update events: never `Trbegin`, `Commit` or
  `Rollback` there. Set an error and the supervisor rolls back and calls `*_ROLLBACK`.
- Control events run outside any transaction and must not write to the database.
- Subprograms shared with events must use the `adxlog` idiom of `database.md` so they never open a
  second transaction. Operations are stateless and may run their own transaction with that idiom.

## Methods and operations

- **Methods tab**: Code (`CODMET`, the value of `AMETHOD`/`AOPERATION`), Return type (`DONMET`),
  *Operation* checkbox (`FLGOPE`), Index (`INDOPE`, operations only). Parameters grid: Code
  (`CODPARMET`) is the `[L]` variable name in the event; mode by address, by value or constant.
- A **method** is stateful: `this` is the current instance. An **operation** is stateless: `this` is
  empty, key segments (named after the key columns) and parameters arrive as `[L]` variables, the
  instance is destroyed at the end; call `AREAD` first if you need data. The error stack dies with
  the instance, so return the status in `ARET_VALUE`. Operations can run asynchronously from a link.
- Call: `[L]RES = fmet INST.YMETHOD(ARG)`. Standard methods: `AINIT()`, `AREAD(key segments)`,
  `AINSERT()`, `AUPDATE()`, `ADELETE()`. The *Standard methods* tab can disable each one.

## Context available in events

| Item | Meaning |
|---|---|
| `this` / `this.APARENT` | Current instance / parent instance of a child |
| `this.snapshot.PROP` | Value at the start of the insert/update (set after the read) |
| `this.ASTALIN` | `[V]CST_ALL` unchanged, `CST_ANEW`, `CST_AUPD`, `CST_ADEL`, `CST_ANEWDEL` |
| `this.ACTX` | Context: `USER`, `AFOLDER`, `LAN`, `LANISO`, `LOGIN` (use it instead of globals) |
| `this.UPDTICK` | Row version maintained by the database; never set it |
| `this.COLL(I).AORDER` | Display order of a collection line |
| `fmet this.ASETATTRIBUTE(PROP, ATTR, VALUE)` | `$isMandatory`; `$isHidden`/`$isDisabled` in representations |

## Errors and ASTATUS

Statuses in increasing order: `[V]CST_ASUCCESS`, `CST_AINFO`, `CST_AWARNING`, `CST_AERROR`,
`CST_AFATAL`; `[V]CST_AOK` is the plain success value (never pass it to `ASETERROR`).

- `[L]ASTATUS = fmet this.ASETERROR(PROPERTY, MESSAGE, STATUS)` (empty PROPERTY = global error),
  `ASETERRORCAT(PROPERTY, MESSAGE, STATUS, CATEGORY)`, `AGETMAXERROR(PROPERTY)`, `AGETMAXERRORALL()`,
  `ASEARCHINFOS` / `AGETNEXTINFOS` to walk the stack, `AGETERRORSFROM(INSTANCE, ENV)` to copy errors.
  The error collection is `this.AERROR`.
- Deleting errors: the events page and the V7 tip write `ADELETEERROR(PROPERTY)`, the error-handling
  guide writes `ADELETERROR(PROPERTY)` / `ADELETERRORALL()`. Check the generated class before use.
- `[L]ASTATUS >= [V]CST_AERROR` on return makes the supervisor stop: control events cancel the
  operation, update events roll back, rules show the error (final control continues to list all).
- Build messages with `mess(NUM, CHAPTER, 1)`, not literals (see `localization.md`).

## Complete specific class script

Setup: persistent class `YCUSTLOG` on custom table `YCUSTLOG [YCL]` (properties `YLOGNUM`, `BPCNUM`,
`YAMOUNT`, `YSTATUS` local menu, `YLOGDAT`); method `YRESET` (return type Integer); Scripts grid line
Specific / `YCUSTLOG_CSPE` / rank 1500 / activity code `YLOG`.

```l4g
# YCUSTLOG_CSPE - specific script of class YCUSTLOG
$EVENTS
  Case [L]CURPTH
    When ""
      Case [L]AEVENT
        When "AINSERT_CONTROL_BEFORE" : Gosub Y_INS_CTL_BEFORE
      Endcase
  Endcase
Return

$PROPERTIES
  Case [L]CURPRO
    When "YAMOUNT" : Gosub Y_PROP_YAMOUNT
  Endcase
Return

$METHODS
  Case [L]AMETHOD
    When "YRESET" : Gosub Y_RESET
  Endcase
Return

$Y_INS_CTL_BEFORE
  # No transaction here: defaults only, no database update
  this.YLOGDAT = date$
  If this.YSTATUS = 0
    this.YSTATUS = 1
  Endif
Return

$Y_PROP_YAMOUNT
  Case [L]ARULE
    When "CONTROL"
      If this.YAMOUNT < 0
        [L]ASTATUS = fmet this.ASETERROR("YAMOUNT", mess(1, 160, 1), [V]CST_AERROR)
      Elsif this.YAMOUNT > 2 * this.snapshot.YAMOUNT and this.snapshot.YAMOUNT > 0
        [L]ASTATUS = fmet this.ASETERROR("YAMOUNT", mess(2, 160, 1), [V]CST_AWARNING)
      Endif
  Endcase
Return

$Y_RESET
  # Stateful method: works on this, returns a status in ARET_VALUE
  If this.YSTATUS = 1
    [L]ARET_VALUE = [V]CST_AWARNING : # already in initial status
  Else
    this.YSTATUS = 1                 : # runs CONTROL / PROPAGATE of YSTATUS
    [L]ARET_VALUE = [V]CST_AOK
  Endif
Return
```

## Using a class from other code

```l4g
Funprog YCUSTLOG_ADD(LOGNUM, BPC, AMOUNT)
Value Char    LOGNUM(), BPC()
Value Decimal AMOUNT
Local Instance YLOG Using C_YCUSTLOG
Local Integer  YSTA
  YLOG = NewInstance C_YCUSTLOG AllocGroup Null
  [L]YSTA = fmet YLOG.AINIT()           : # INIT rules + AINIT event
  If [L]YSTA < [V]CST_AERROR
    YLOG.YLOGNUM = LOGNUM
    YLOG.BPCNUM  = BPC                  : # CONTROL / PROPAGATE fire here
    YLOG.YAMOUNT = AMOUNT
    [L]YSTA = fmet YLOG.AINSERT()       : # controls, events, insert
  Endif
  FreeGroup YLOG
End [L]YSTA
```

Read and update follow the same shape: `fmet YLOG.AREAD(LOGNUM)`, assign properties,
`fmet YLOG.AUPDATE()`. `SetInstance [YCL] With YLOG` / `SetInstance YLOG With [YCL]` copy between an
instance and a table buffer (arrays excepted). `FreeInstance X` frees one instance, `FreeGroup X`
everything allocated in its group. `Local Instance ... Using` is mandatory (`R_<REP>` for a
representation). Calling `AINIT()` yourself is required when a script creates the instance.

## Collections

- A collection holds child instances: `INST.LINES(I).PROP`; test `INST.LINES(I) <> null`, bound loops
  with `maxtab(INST.LINES)`. Create children with `NewInstance C_CHILD AllocGroup PARENT` so that
  `FreeGroup PARENT` frees them. Up to 100 collections per class.
- A simple property array becomes a generated child class: access `INST.COLLECTION(I).PROPERTY`.
- `fmet this.ADDLINE("LINES", [V]CST_ALASTPOS)` returns the new index or `[V]CST_ANOTDEFINED`
  (`CST_AFIRSTPOS` or a position also accepted); `ADELLINE(COLL, POS)` marks a line deleted;
  `AGETINDBYLINE(COLL, LINE)` finds an index. Lines with `ASTALIN` = `CST_ADEL` / `CST_ANEWDEL` are gone
  from the UI and are deleted at update.
- `SetInstance` does not copy array columns of a table buffer: loop and assign them.

## What not to use

- `Class ... Endclass`, `Public`/`Private` declarations, `Extends`, `super`: not X3 syntax.
- `GESECRAN` routines for errors, and `Infbox`/`Errbox`/`Qstbox`/masks in class code (Classic-only,
  deprecated in V7 mode; no UI exists in service mode).
- `Trbegin`/`Commit`/`Rollback` in events; global variables instead of `this.ACTX`.
- Codes starting with W (generated), `_A*` supervisor internal methods, `Callmet` (internal keyword).
- Editing `C_*.stc` or other generated scripts.

## Gotchas

- Always assign `[L]ASTATUS` from `ASETERROR`: the message goes to the error stack, but the
  supervisor decides to abort by testing `ASTATUS` when the event returns.
- An assignment in `AREAD_AFTER` does not run CONTROL and becomes the snapshot value.
- `$METHODS` runs only in the defining class's scripts; a child class method is not dispatched to the
  parent's script, unlike CRUD events.
- Hard-coded texts in `ASETERROR` are not translated: use `mess`.
- Validate after every dictionary change (property, method, script line): the generated code is
  what runs.
